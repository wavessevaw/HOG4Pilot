# HOG4Pilot

Начальная реализация ядра 0.1 на Rust. Это не готовая система 1.0 и не Windows desktop-сборка.

## Запуск

Установите стабильный Rust. В каталоге проекта:

```sh
cargo test
cargo run --release
```

Программа выполняет полностью локальную симуляцию трёх виртуальных RGB Dimmer приборов, перехода и потери связи. Сеть из CLI недоступна. Виртуальные профили нельзя применять к реальным приборам.

## Реализовано

- Структуры профиля, прибора, светового состояния; 8-битные интенсивность и RGB.
- Независимая валидация полного кадра, адресации, происхождения профиля, нейтральных значений и диапазонов.
- Необратимая в рамках сеанса остановка при конфликте источников.
- Линейная интерполяция состояния; симулятор и имитация отказа.
- Настоящий UDP ArtDMX unicast адаптер, полный кадр 512 каналов, sequence, ограничение частоты.
- Автоматические тесты, включая реальную UDP передачу только на loopback.

## Ограничения

Адаптер — низкоуровневая библиотека, не готовый контроллер площадки. Проверенность профиля и baseline задаются вызывающим доверенным кодом; полноценная система свидетельств проверки ещё не реализована. Перед физическим применением необходимы управление жизненным циклом выходного процесса, watchdog, проверка владения всей вселенной и физической схемы отказа. Отправленный UDP пакет не подтверждает исполнение. Остановка отправки не останавливает прибор. Ошибки сети должен обрабатывать владелец сеанса; CLI демонстрирует остановку при отказе симулятора. Уже полученный кадр не отзывается вызовом stop; поэтому адаптер нельзя предоставлять интерфейсу или ИИ.

Ещё не реализованы: Tauri/React, SQLite, постоянный журнал, 16 бит, sACN, discovery/RDM, импорт профилей, пространственная модель, полноценное воспроизведение по времени, Hog, OCR и ИИ. Физических испытаний не проводилось. Возможности Hog не заявляются до проверки официальной документации для конкретной версии OS.
